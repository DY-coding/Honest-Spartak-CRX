# Honest Spartak (Chrome Extension)

Контентное браузерное расширение, которое очищает новостную ленту ФК «Спартак» сайта `sports.ru` от желтой прессы, кликбейта, рекламы и нежелательных персон. Проект реализует сложную логику фильтрации контента и динамического изменения DOM на лету.

## Основные возможности

* Автоматическая фильтрация: скрытие новостей по ключевым словам и URL-шаблонам на основе черного списка (вынесен в отдельный редактируемый модуль constants.js).
* Загрузка и просмотр содержимого новостей в модальном окне без покидания страницы.
* Собственный механизм подавления всплывающих окон и анти-адблок систем.
* Фоновая проверка новых новостей через `Service Worker` с уведомлениями на иконке расширения.
* Динамическая панель статистики отфильтрованных новостей с визуализацией прогресс-бара.

## Технический стек и методы JavaScript

В проекте сделан упор на нативный JavaScript (Vanilla JS) и современные браузерные API без использования тяжелых фреймворков.

### 1. Реактивность и мониторинг DOM (MutationObserver)

Для обработки контента, который подгружается динамически при скролле, используются экземпляры `MutationObserver`.

* Анализ добавления новых новостей, прогонка их через фильтры и обновление счетчика статистики в реальном времени.
* Слежение за появлением рекламных элементов и мобильных навигационных панелей и их мгновенно скрытие.


### 2. Асинхронное взаимодействие (Fetch & DOMParser)

Реализована логика «превью» новостей:

* **Fetch API**: Используется для фонового получения HTML-кода статьи при клике на заголовок.
* **DOMParser**: Парсит полученную строку в виртуальное DOM-дерево. Это позволяет извлечь только полезный текст, отсекая рекламные блоки и скрипты стороннего сайта перед рендерингом в модальном окне.

### 3. Фоновые процессы (Service Workers & Alarms)

Файл `background.js` работает как независимый поток:

* **Chrome Alarms API**: Настроен планировщик, который каждые 15 минут делает фоновый запрос к серверу для поиска новых новостей.
* **Badge & Tooltip Management**: Динамическое обновление количества новых новостей на иконке расширения (`setBadgeText`) и формирование списка их заголовков в тултипе при наведении.

### 4. Хранилище и состояние (Chrome Storage API)

Для отслеживания новых новостей используется `chrome.storage.local`.

* Алгоритм сравнивает текстовые сигнатуры текущих новостей с массивом прочитанных в хранилище, динамически помечая новые элементы на странице классом `.unread` для визуального выделения.

### 5. Модульность и архитектура

* Использование **ES-модулей** (`import/export`) для организации констант и списков фильтрации.
* Организована система обмена сообщениями между `content.js` и `background.js` для синхронизации настроек и управления UI.
